# Релокот — помощник по переезду

Ищет вакансии с визой и релокацией, программы переезда и события
(дедлайны, вебинары, ярмарки), сохраняет их, ставит оценки 1–10.

## Запуск (5 минут)

1. Установи **Python 3.10 или новее**: https://www.python.org/downloads/
   (на Windows при установке поставь галочку **Add Python to PATH**).
2. Распакуй папку `relokot` куда угодно.
3. Запусти:
   - **Windows:** двойной клик по `start.bat`
   - **Mac / Linux:** в терминале `./start.sh`
4. Браузер откроется сам на http://127.0.0.1:8000.
   Остановить сервер: закрыть окно или `Ctrl+C`.

Первый запуск дольше: ставятся библиотеки.

## Что работает без ключей

- **Вакансии** из Arbeitnow (Европа, в основном Германия, много вакансий с визой)
  и Jobicy (удалёнка). Нажми «Вакансии» → «Искать на сайтах».
  Пустой запрос ищет по анкете, можно вписать своё: `python`, `nurse`, `logistics`.

## Ключи (по желанию) — в файле `.env`

Файл `.env` создаётся при первом запуске из `.env.example`. После изменения перезапусти сервер.

| Ключ | Что даёт | Где взять |
|---|---|---|
| `ANTHROPIC_API_KEY` | ИИ-поиск программ переезда и событий на официальных сайтах | console.anthropic.com → API Keys (платно, по факту использования) |
| `ADZUNA_APP_ID`, `ADZUNA_APP_KEY` | + вакансии из Adzuna (Германия, Нидерланды, Польша, Великобритания, Канада и др.) | developer.adzuna.com (бесплатно) |

ИИ-поиск одного раздела обычно занимает 1–3 минуты и стоит порядка нескольких
десятков центов (токены + плата за веб-поиски). Результат кэшируется на 12 часов.

## Как считается рейтинг вакансий (scoring.py)

- **Надёжность**: доверие к источнику, указана ли зарплата и компания, свежесть
  объявления, «красные флаги» (просят оплатить сбор, связь через Telegram/WhatsApp,
  личная почта, «гарантия визы», «$3000 в неделю»).
- **Лёгкость пути**: спонсорство визы, удалёнка, помощь с переездом; минус — «визу не спонсируем».
- **Скорость**, **Дешевизна** (релокационный пакет, удалёнка), **Перспектива ПМЖ** (по стране).
- **Совпадение %**: сфера, регион, английский/немецкий, опыт.

Это эвристики по тексту объявления — они помогают отсеять мусор, но не заменяют
проверку компании. Все правила — простые строки в `scoring.py`, их легко менять.

## Структура

```
server.py      — веб-сервер (FastAPI), отдаёт сайт и API
sources.py     — источники вакансий (Arbeitnow, Jobicy, Adzuna) + кэш 30 мин
scoring.py     — оценки 1–10, красные флаги, совпадение с анкетой
ai.py          — ИИ-поиск программ и событий (Claude + веб-поиск)
mock_data.py   — тестовые данные (RELOKOT_MOCK=1)
static/index.html — весь интерфейс (одна страница, чистый JS)
tests/         — тесты: python -m pytest -q
```

API: `GET /api/health`, `POST /api/jobs/search`, `POST /api/programs/search`,
`POST /api/events/search`. Документация: http://127.0.0.1:8000/docs

Данные пользователя (анкета, сохранённое, заметки) хранятся в браузере.

## Тестовый режим

`RELOKOT_MOCK=1` в `.env` — сервер отдаёт ненастоящие данные без интернета.
Удобно, чтобы проверить интерфейс.
